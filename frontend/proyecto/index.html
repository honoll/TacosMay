Proyecto escolar

Cómo usa Redis esta tienda

Proyecto final de Bases de Datos Avanzadas (Universidad Anáhuac): una tienda en línea con el modelo Clave-Valor, sobre Redis Cloud. Todos los datos viven en la nube; el servidor solo los lee y los escribe.

Qué hace Redis en cada paso

El mismo recorrido de la demo. Cada clave lleva el prefijo tm:; las llaves {…} son el id de cada guiso, cliente o pedido.

  1. 1

    Catálogo

    tm:guiso:{id} Hash tm:guisos Set

    Cada guiso es un Hash con su nombre, precio, porciones y existencias. El Set guarda los ids de todos: así se listan sin recorrer la base con KEYS.

    Ver el catálogo
  2. 2

    Más vendidos

    tm:guisos:vendidos Sorted Set

    El puntaje de cada guiso son las unidades vendidas. Redis lo mantiene ordenado: la fila «Lo que más sale» son los cinco de arriba.

    Ver lo que más sale
  3. 3

    Carrito que expira

    tm:carrito:{userId} Hash con TTL

    Un campo por guiso con su cantidad. Vive 30 minutos y cada cambio renueva el tiempo con EXPIRE; si se abandona, Redis lo borra solo. El reloj y el anillo del carrito son ese TTL.

    Ver el carrito
  4. 4

    Compra sin vender de más

    WATCH + MULTI/EXEC Transacción

    Confirmar el pedido descuenta existencias, suma al ranking, guarda el pedido y borra el carrito, todo o nada. Si otro cliente compró lo mismo en medio, WATCH cancela la transacción y la tienda responde que ya no alcanza.

    Confirmar desde el carrito
  5. 5

    Historial de pedidos

    tm:pedidos:{userId} List tm:pedido:{id} Hash

    Cada pedido nuevo entra al principio de la lista del cliente con LPUSH; el pedido guarda sus guisos con el precio del momento de la compra.

    Ver mis pedidos
  6. 6

    Consecutivos

    tm:seq:{entidad} String

    Un contador por tipo de dato: INCR da el siguiente id de guiso, cliente o pedido sin que dos peticiones reciban el mismo.

    Ver el número de un pedido

Para probarla

  • Cliente: crea una cuenta, tarda segundos. Se guarda en tm:user:{email}, con la contraseña cifrada.
  • Administrador (alta, cambios y baja de guisos): las credenciales se entregan con el proyecto.
  • Demo guiada de la exposición: el flujo completo paso a paso, con cada petición, los comandos de Redis y la respuesta real. Registra dos clientes de demostración y compra de verdad.
